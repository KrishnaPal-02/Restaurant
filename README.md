# 🍴 The Gourmet Table - Restaurant Website

## 📌 About The Project
The Gourmet Table is a modern and responsive restaurant website created using HTML, CSS, and JavaScript. It provides an elegant platform to explore the restaurant's menu, special offers, opening hours, and table reservation options.

## ✨ Features
- Attractive and responsive homepage.
- Restaurant information and opening hours.
- Special offers and discounts.
- Food menu with images and prices.
- Interactive table reservation form.
- JavaScript form validation.
- Reservation confirmation message.
- Interactive FAQ accordion.
- Smooth navigation between sections.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Unsplash Images
